Teoria da Informação · Claude E. Shannon, 1948

Entropia de Shannon

A entropia mede a quantidade mínima teórica de bits necessários para representar uma mensagem. É o fundamento matemático de toda compressão de dados. Shannon provou que nenhum sistema de codificação pode usar, em média, menos bits do que a entropia da fonte.

Teorema (Shannon, 1948): Para uma fonte discreta sem memória com alfabeto {x₁,...,xₙ} e probabilidades {p₁,...,pₙ}, a entropia é:

H(X) = −∑ pᵢ · log₂(pᵢ)

A entropia máxima é log₂(n) bits, atingida quando todos os símbolos são equiprováveis. A entropia mínima é 0, quando um símbolo tem probabilidade 1.

Codificação · David A. Huffman, 1952

Codificação Huffman

Algoritmo guloso que constrói um código de prefixo ótimo. Prova que símbolos mais frequentes recebem códigos mais curtos. Base do JPEG, MP3, ZIP e DEFLATE.

Teorema de Optimalidade de Huffman: Para qualquer fonte discreta sem memória, o código de Huffman produz o código de prefixo com comprimento médio mínimo L̄ = ∑pᵢ·lᵢ. Não existe código de prefixo com menor comprimento médio esperado.

Código Corretor de Erros · Richard Hamming, 1950

Código de Hamming (7,4)

O código de Hamming (7,4) transmite 4 bits de dados usando 7 bits, adicionando 3 bits de paridade que permitem detectar e corrigir qualquer erro de 1 bit. É a base de memórias ECC e RAIDs.

Distância de Hamming: d(u,v) = número de posições onde u e v diferem. Um código com distância mínima d_min detecta até d_min−1 erros e corrige até ⌊(d_min−1)/2⌋ erros. O Hamming(7,4) tem d_min=3, corrigindo 1 erro.

Matriz Geradora H (7×4) Matricial

P = [1 1 0 1] Posições de paridade cobrem subconjuntos específicos [1 0 1 1] de posições pelo algarismo 1 em sua representação binária. [0 1 1 1] Codeword = G · d onde G é a matriz geradora sistemática 7×4
Prova de Correção (1 erro): Após receber r = c + e (c=codeword, e=vetor de erro com peso 1), calculamos a síndrome s = H·r = H·c + H·e = 0 + H·e = H·e. Como H·eᵢ = coluna i de H = representação binária de i, a síndrome aponta diretamente para a posição errada. ■
Computabilidade · Alan Turing, 1936

Máquina de Turing

Uma Máquina de Turing é um modelo matemático abstrato que define o que pode ser computado. Turing provou que qualquer função computável por um algoritmo pode ser computada por ela. Toda CPU moderna é uma implementação física desta abstração.

Tese de Church-Turing: Qualquer função que pode ser calculada por um procedimento mecânico pode ser calculada por uma Máquina de Turing. Formalmente: TM = (Q, Σ, Γ, δ, q₀, q_accept, q_reject) onde δ: Q×Γ→Q×Γ×{L,R} é a função de transição.

Complexidade Algorítmica · Kolmogorov, 1965

Complexidade de Kolmogorov

K(x) é o comprimento do menor programa que produz x. É incomputável no caso geral, mas pode ser aproximado pela taxa de compressão. Mede a "aleatoriedade intrínseca" de uma sequência binária.

Teorema da Invariância: Para quaisquer dois interpretadores U e V, |K_U(x) − K_V(x)| ≤ c onde c é uma constante que depende apenas de U e V, não de x. Portanto K(x) é independente (até constante aditiva) da linguagem de programação escolhida.

Análise por Janela Deslizante

Por que é incomputável: Suponha que K seja computável. Construa o seguinte programa: "enumere todas as strings por tamanho e imprima a primeira com K(x) > 10^6". Este programa tem tamanho ~1000 bits mas produz uma string com K > 10^6. Contradição. Logo K é incomputável (análogo ao Problema da Parada). ■
