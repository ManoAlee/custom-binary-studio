Código Corretor de Erros · Richard Hamming 1950

Código de Hamming (7,4)

Transmite 4 bits de dados com 3 bits de paridade (7 bits total). Detecta e corrige qualquer erro de 1 bit. Base de memórias ECC, RAID e comunicações espaciais.

d_min = 3 → detecta 2 erros, corrige 1. Síndrome s = s₁+2s₂+4s₄ aponta diretamente para a posição errada.
