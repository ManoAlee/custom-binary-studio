# ⚡ NEXUS — Ecossistema Computacional Avô da WebGPU

> **WebGPU · Neuro-Anatomia 3D · 4D Tesseract · Relatividade de Kerr · Filosofia & Ontologia do Impossível**

NEXUS é um ecossistema computacional e estético de alta performance, unindo matemática pura, física quântica/relativística, teoria da informação e filosofia ontológica em uma interface interativa sem precedentes.

---

## 🚀 Módulos do Sistema

1. **GPU (Smart Matter):** Autômato celular de reação-difusão em shaders WebGPU / WebGL2.
2. **3D (Universo Binário):** 8.192 bits em órbita espacial seguindo a proporção áurea ($\Phi \approx 1.618$).
3. **NEURO (Anatomia 3D Real):** Córtex cerebral 3D com giros, sulcos, sistema límbico (Hipocampo/Amígdala) e condução axonal.
4. **A.P. (Potencial de Ação Hodgkin-Huxley):** Integração numérica das equações diferenciais não-lineares da membrana neuronal (1952).
5. **VALIS (Sintonizador de Qualia):** Síntese harmônica de formas de onda cerebrais (Alfa, Beta, Teta, Gama).
6. **CHAOS (Atratores Estranhos 3D):** Dinâmica não-linear dos sistemas de Lorenz e Rössler.
7. **FRAC (Geometria Fractal GLSL):** Renderização ultra-fluida do Conjunto de Mandelbrot e Julia.
8. **WAVE (Interferência de Ondas):** Equação de onda 2D com Fenda Dupla de Young e óptica quântica.
9. **4D (Projeção Hiper-Espacial):** Tesseracto 4D, Glome, Célula-120 e Variedades de Calabi-Yau (Teoria das Cordas).
10. **BH (Relatividade Geral de Kerr):** Lente gravitacional relativística, ergosfera a $0.98c$ e efeito Doppler/Redshift.
11. **IMP (O Laboratório do Impossível):** Simulação da Dialética de Hegel (Tese-Antítese-Síntese), Dasein de Heidegger, Desconstrução de Derrida, Rizoma de Deleuze e Métrica Warp de Alcubierre.
12. **COS (Cosmos N-Corpos):** Simulação gravitacional N-Corpos com colisão galáctica.
13. **WOLF (Autômato de Wolfram):** Regra 30, Regra 110 e computação universal.
14. **FFT (Análise Espectral):** Transformada Rápida de Fourier de sinais com osciloscópio.
15. **H(X) (Shannon & Huffman):** Entropia de informação $H(X) = -\sum p_i \log_2 p_i$.
16. **ECC (Hamming):** Correção quântica/binária de erros de memória.
17. **TM (Turing & ALU):** Máquina de Turing de fita infinita com Unidade Lógica e Aritmética.

## 🛠️ Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/ManoAlee/custom-binary-studio.git

# Acesse o diretório
cd custom-binary-studio

# Inicie um servidor HTTP local
python -m http.server 5500
```

Abra o navegador em: `http://localhost:5500/nexus.html`
